Three ways to age a page

The effects are variable axes, so they move smoothly, mix freely and combine freely: any weight, any mix of the three.

Sunday

Light Burn BURN −100 to 100

Too much light or too little. Negative values let the ink spread into soft, heavy shapes; positive ones burn the strokes down to thin hairlines.

Sunday

Ink Bleed INKB 0 to 100

Ink soaking into cheap paper: corners round off, counters close up, letters start to touch.

Sunday

Worn Print WORN 0 to 100

A tired press and a dry roller. Edges break up and the color thins out, like a flyer left in the sun.

Use it on the web

Two builds, each a pair of variable files, roman and italic. Sunday Serif is the light one for text: every weight in about 45 KB a style. Sunday Serif FX adds the three effects and weighs about 1 MB a style, so load it only where effects show.

1 Load the fonts

Put the WOFF2 files from the download next to your CSS, declare them with their weight range and preload the roman text file.

CSS
@font-face {
  font-family: "Sunday Serif";
  src: url("fonts/SundaySerifText-Variable.woff2") format("woff2");
  font-weight: 400 600;
  font-style: normal;
  font-display: swap;
}
@font-face {
  font-family: "Sunday Serif";
  src: url("fonts/SundaySerifText-Italic-Variable.woff2") format("woff2");
  font-weight: 400 600;
  font-style: italic;
  font-display: swap;
}
/* Only where you use the effects */
@font-face {
  font-family: "Sunday Serif FX";
  src: url("fonts/SundaySerif-Variable.woff2") format("woff2");
  font-weight: 400 600;
  font-display: swap;
}

<!-- in <head> -->
<link rel="preload" href="fonts/SundaySerifText-Variable.woff2"
      as="font" type="font/woff2" crossorigin>

2 Set the type

Any weight from 400 to 600 works, in between too. Bold in your markup maps to SemiBold.

CSS
body {
  font-family: "Sunday Serif", Georgia, serif;
  font-weight: 400;  /* Regular */
}
h2 { font-weight: 500; }  /* Medium */
h1 { font-weight: 560; }  /* anything between 400 and 600 */
em { font-style: italic; }

3 Add an effect

Effects need the FX build. Mix the axes, or drive them with custom properties to animate them. Leave out an axis and it stays at 0, the clean print.

CSS
.poster {
  font-family: "Sunday Serif FX", "Sunday Serif", serif;
  font-variation-settings: "BURN" -15, "INKB" 20, "WORN" 15;
}

/* Animate one axis with a registered property */
@property --worn { syntax: "<number>"; inherits: true; initial-value: 0; }
.fade-in {
  font-family: "Sunday Serif FX", "Sunday Serif", serif;
  font-variation-settings: "WORN" var(--worn);
  transition: --worn 1.2s ease;
}
.fade-in:hover { --worn: 80; }

4 Blur, in any color

Sunday Serif Blur is a color font (COLRv0, every modern browser). Its sharp core takes the text color; the eight halo layers are black by default: recolor them with a palette, keeping each layer's transparency.

CSS
@font-face {
  font-family: "Sunday Serif Blur";
  src: url("fonts/SundaySerifBlur-Regular.woff2") format("woff2");
  font-display: swap;
}
@font-palette-values --paper {
  font-family: "Sunday Serif Blur";
  override-colors:
    0 #ffffff12, 1 #ffffff14, 2 #ffffff17,
    3 #ffffff1a, 4 #ffffff1f, 5 #ffffff24,
    6 #ffffff2e, 7 #ffffff40;
}
.dreamy {
  font-family: "Sunday Serif Blur", "Sunday Serif", serif;
  font-palette: --paper;
}

Sunday Serif is released under the SIL Open Font License 1.1. Use it for anything: websites, apps, books, logos, products you sell. Embed it, change it, ship it with your work.

The one thing you can't do is sell the font files on their own. If you change the fonts and share them, give them a different name.
